## Using with pnpm and TypeScript

This package is configured for TypeScript and pnpm.

- Install dependencies:
  - pnpm install
- Type check:
  - pnpm run typecheck
- Build:
  - pnpm run build
- Run tests:
  - pnpm run test

Node.js 20+ is required. The TypeScript compiler outputs to `dist/` and type declarations are emitted alongside JavaScript.
