# domain

Latest version of the library domain

## Module format

This package is published as ECMAScript Modules (ESM). The package.json has `"type": "module"` and the TypeScript compiler outputs native ESM to `dist/` with declarations alongside.

- Node.js 20+ is required.
- Import using standard ESM syntax:
  - import { Something } from '@means-of-production/domain'

## Using with pnpm and TypeScript

This package is configured for TypeScript and pnpm.

- Install dependencies:
  - pnpm install
- Type check:
  - pnpm run typecheck
- Build:
  - pnpm run build
- Run tests:
  - pnpm run test
